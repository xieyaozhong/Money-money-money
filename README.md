# Money-money-money｜股票智慧分析儀

輸入股票代號，自動整合歷史價格、技術面、新聞情緒、台股官方估值、未來價格情境與風險部位計算。

## 支援輸入

- 台股上市：`2330` 或 `2330.TW`
- 台股上櫃：`XXXX.TWO`
- 美股：`AAPL`、`NVDA`、`TSLA` 等 Yahoo Finance 可識別代號

純數字代號會先嘗試 `.TW`，失敗再嘗試 `.TWO`。

## 分析內容

### 市場與技術面
- 近 2 年日線價格 / 成交量資料
- EMA20 / EMA60
- RSI(14)
- MACD(12,26,9)
- ATR(14)
- 20 / 60 日動能
- 20 日量比
- 20 日支撐 / 壓力
- 年化歷史波動率
- 60 日對數價格趨勢回歸

### 未來情境
以近期日對數報酬估計漂移與波動率，使用 GBM（Geometric Brownian Motion）執行 3,000 次蒙地卡羅情境，輸出：

- 5 交易日 P10 / P50 / P90
- 20 交易日 P10 / P50 / P90
- 60 交易日 P10 / P50 / P90
- 各期間模擬終值高於目前價格的比例

這些數字是機率情境，不是保證目標價。

### 台股官方估值
台灣上市股票會嘗試讀取臺灣證券交易所 OpenAPI：

- 本益比 PE
- 殖利率
- 股價淨值比 PB
- 公司基本名稱

### 新聞情緒
嘗試讀取 Google News RSS，針對近期新聞標題做簡單正負面關鍵字評分。若新聞來源暫時不可用，新聞權重會自動歸零，不會用假資料補值。

## 買入金額怎麼算

使用者輸入：

1. 可投資資金
2. 單筆最大風險百分比
3. 單一股票最大配置百分比

模型先用 ATR 與價格百分比估算停損距離，再同時計算：

```text
風險股數 = (總資金 × 單筆風險%) ÷ 每股停損距離
配置股數 = (總資金 × 單股配置上限%) ÷ 現價
模型最大股數 = min(風險股數, 配置股數)
```

接著把模型最大股數拆成 40% / 30% / 30% 三段，分別搭配 EMA20 回踩、較深支撐與突破確認條件。

## 資料來源與部署注意

本專案設計為純前端 GitHub Pages 頁面，不需把 API Key 寫進公開 repo。

Yahoo Finance 的瀏覽器端請求可能受到 CORS 或限流影響，因此頁面內建多路請求 fallback。若免費跨網域來源臨時不可用，頁面會顯示錯誤而不是生成假的行情。

若之後要做成更穩定的正式版本，建議增加自己的 serverless backend（例如 Cloudflare Worker / Vercel Function），並接入有正式授權與 SLA 的市場、財報與新聞 API。

## 風險聲明

本專案提供的是資料分析、教育與風險管理輔助，不構成投資招攬、保證獲利、投資顧問或自動交易指令。金融市場可能受到財報、政策、流動性、突發事件與資料延遲影響，實際價格可能顯著偏離模型情境。
